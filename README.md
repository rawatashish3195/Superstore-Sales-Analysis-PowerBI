# 📊 Superstore Sales Analysis – Power BI Dashboard

## 📌 Project Overview
This project presents an interactive Power BI dashboard built using the Global Superstore dataset.  
The goal of this analysis is to derive actionable business insights from sales, profit, customer, and regional performance data.

This dashboard simulates real-world business reporting used by management teams to monitor KPIs and make data-driven decisions.

---

## 🛠️ Tools & Technologies Used
- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Cleaning & Transformation
- Interactive Visualizations

---

## 📂 Dataset
- Global Superstore Dataset
- Contains data related to:
  - Orders
  - Sales
  - Profit
  - Customers
  - Regions
  - Categories & Sub-Categories

---

## 📈 Dashboard Pages

### 1️⃣ Executive Overview
Key KPIs:
- Total Sales
- Total Profit
- Profit Margin %
- Total Quantity Sold

Visuals:
- Profit by Region
- Sales & Profit Trend by Year
- Loss & Profit by Sub-Category

This page helps management quickly understand overall business performance.

---

### 2️⃣ Segment & Customer Analysis
Key Insights:
- Profit vs Sales by Segment
- Top 10 Customers by Sales & Profit

This page helps identify:
- High-value customers
- Most profitable segments
- Customer performance distribution

---

## 🔍 Key Business Insights
- Central region generates highest profit.
- Certain sub-categories contribute to losses.
- Consumer segment drives highest revenue.
- Sales show consistent year-over-year growth.
